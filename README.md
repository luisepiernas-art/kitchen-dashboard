# Kitchen Smart Dashboard 🍽️

Dashboard familiar interactivo para cocina diseñado para ejecutarse en un dispositivo BQ Android de 5.5" en modo kiosco.

## Características
- 🕒 Reloj y fecha en vivo con actualización continua.
- ⛅ Meteorología en tiempo real para Torrejón de Ardoz.
- 🥗 Menú semanal completo: Comida escolar (colegio niña 8 años), almuerzo en casa y cena familiar compensada.
- 📅 Línea de tiempo diaria con hitos y horarios clave.
- 🛒 Lista táctil interactiva para compras y tareas de cocina.
- ⏱️ Temporizador de cocina rápido con alertas sonoras.
- 📱 Sincronización automática con `menu.json`.
